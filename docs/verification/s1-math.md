## 反向探针

仅临时破坏本轮 AI 新增代码，未改用户乘法。每次只改变一处，重新构建并要求 TRX 中 `executed > 0` 且 `failed > 0`；不能用编译失败充当断言变红。随后精确恢复源文件，最终重新构建运行完整验收。

| 故意破坏 | 实际捕获 |
| --- | --- |
| 除法半途比较从 `>=` 改为 `>` | 16 个边界用例中 4 个失败 |
| 平方根去掉最后舍入进位 | 7 个边界用例中 1 个失败 |
| 随机数不更新状态 | 黄金序列测试 1/1 失败 |
| 随机数关闭拒绝区间 | 定向拒绝测试 1/1 失败 |
| 三角插值读取下一样本作为首样本 | 基点测试 1/1 失败 |
| 长度退回 `sqrt(LengthSquared)` | 大向量和极值测试 1/1 失败 |
| 归一化仅返回缩放向量 | 大向量和极值测试 1/1 失败 |
| 点积遗漏 Z 分量 | 百万向量测试实际执行并在错误输入处失败 |
| 生成表首样本改 1 raw | 只读 `--check` 退出 1；恢复后退出 0 |

表探针首次定位断言把首尾的零样本误认为唯一，未进行表修改即停止；随后改为只修改首样本，单独验证成功。这是探针脚本问题，不是产品检查失败。其余 8 项在此前均已捕获并恢复。

现有乘法测试本身也在用户前一版本实际失败（45 项失败、百万组 143,732 组不一致），补齐舍入后转绿。本轮没有增加或修改乘法断言来适配实现。
